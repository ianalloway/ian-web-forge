Selected Projects

SpendAudit | LLM auditor benchmark

Built a 320-item benchmark testing whether LLM auditors match an executable payment policy, with paired prompt-injected memos. Requiring rule-by-rule evidence cut false approvals on clean traces from 34 to 6 and from 47 to 18; injected memos still caused false approvals for every model. The data, all model responses and a recount script are public.

github.com/ianalloway/spendaudit

Built a Python toolkit for response-order sensitivity, irrelevant-padding effects, prompt-injection checks, repeated-score consistency, judge panels, and calibration. Uses deterministic fixtures and tests; mock-judge demonstrations do not establish production-model accuracy.
